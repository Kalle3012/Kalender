# DayFlow – mein persönlicher Alltagsplaner

Eine Web-App für Aufgaben, Termine und Fußball-Quoten – gebaut mit HTML, CSS und Vanilla JavaScript, ohne Frameworks.

**Live:** https://kalle3012.github.io/Kalender/

## Funktionen

- Startseite mit Begrüßung, Tagesfortschritt und „Als Nächstes“
- Aufgaben per Sprache eintragen („Morgen um 10 Uhr Zahnarzt, wichtig“)
- Aufgaben anlegen, abhaken und löschen (mit Rückgängig)
- Fußball-Spiele des Tages mit 1/X/2-Quoten und Hinweisen auf interessante Quoten (über The Odds API, eigener kostenloser Schlüssel nötig)

## Daten

Alle Aufgaben und der API-Schlüssel werden nur im Browser gespeichert (localStorage) – nicht in diesem Projekt.

## Dateien

- `index.html` – Struktur
- `style.css` – Design
- `script.js` – Funktionen
